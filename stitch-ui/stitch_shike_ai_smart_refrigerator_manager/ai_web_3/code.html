01

备料与蛋液调理

耗时约 3 分钟 · 刀工与蓬松技巧
基础备菜

西红柿洗净切成均等滚刀块备用；将 3 枚鲜鸡蛋打入大碗中，加入 1g 低钠盐和一汤匙温水（约 15ml），用筷子顺时针快速搅打，直至表面泛起密布微小气泡。

local_fire_department 主厨密诀：温水搅蛋法可降低蛋液受热紧缩度，使滑炒出的蛋块嫩度提升 30%，不易发柴。
02

滑炒热蛋

火候把控 · 蛋液微凝立即起锅
关键控温步

平底不粘锅烧至中高火，倒入 10ml 底油。待油面微起波纹（约六成热）时倒入搅好的蛋液。握住锅铲由外向内轻轻推散堆叠，待蛋液底部刚凝固、表面仍有湿润光泽时立刻关火盛出备用。

timer
滑蛋倒计时建议 01:45
03

煸炒番茄出浓沙汁

天然果酸析出 · 拒绝添加番茄酱
沙化出汁

无需另起新锅，利用锅底少许余油（若较干可补 5ml），倒入切好的番茄块中火慢炒。用锅铲背轻轻按压番茄边缘，激发果汁自然渗出，翻炒约 2 分钟直至汤汁变得浓稠挂铲。

timer
慢煸出沙计时 02:00
04

合炒出锅与温拌时蔬

入味收汁 · 爽脆时蔬平衡
成盘收尾

将备好的滑蛋回锅，淋入 5ml 特级生抽与剩余 1g 盐，大火快速翻颠炒匀 15 秒使蛋块均匀裹上番茄酸甜汁，撒上翠绿葱花即可装盘。另起奶锅烧沸水，将半包娃娃菜焯水 60 秒捞出沥干，滴两滴香油摆于旁侧。

成品特写：浓稠裹汁
质感验收标准

• 盘底略有红润挂壁沙汁，但不水塌
• 蛋块呈明亮蛋黄微焦淡色，入口绵软
• 娃娃菜鲜脆碧绿，清甜解腻
