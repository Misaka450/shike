01 备料与蛋液调理
预估 3 分钟

打入 3 枚鸡蛋，加 1 汤匙温水与 1g 盐，顺时针充分打散至表面浮起微密气泡。番茄去蒂切均匀滚刀块；娃娃菜对剖洗净备用。

tips_and_updates
主厨秘诀：温水搅蛋法可降低蛋液受热紧缩度，使滑炒出的蛋块嫩度提升 30%，口感如布丁般细腻。
02 滑炒热蛋 (微凝即起)
关键控温

热锅冷油下 10ml 食用油，大火烧至六成热（微冒轻烟）。倒入蛋液，用锅铲从边缘向中央轻推，形成大朵凝云状，八成熟即刻盛出，勿炒老。

04 合炒入味与温拌时蔬
